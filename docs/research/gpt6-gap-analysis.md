# GPT-6（Astra）と SIDRA AI の差分分析（2026-09-07）

社長指示「gdp6と現在のシドラAIの違いを考えて差を埋めて」への回答文書。
GPT-6 Astra は OpenAI が 2026-09-03 に公開した最新フラッグシップ。
事実は下記出典から。**精読したのは japan-ai.co.jp の解説記事**
（2026-09-07 確認）。リリース日等は検索結果の複数記事で一致を確認したが
未精読（evolink.ai / uravation.com / note.com）。数字は精読元のみ採用。

## 1. GPT-6 Astra の事実（2026-09-07 確認・japan-ai.co.jp/media/10406/）

- 文脈 105 万トークン・最大出力 12.8 万。長文検索 MRCR v2 96.3%。
- **エージェント動作が主眼**: 画面を見てマウス/キーボードで PC 作業を実行
  （OSWorld 2.0 72.6%）。Unity / Godot / Blender の操作に対応、
  ゲーム開発企業 Playco は「手作業の修正が 50% 減」と報告。
- ネイティブマルチモーダル（テキスト・画像・音声・動画統合）。
- 料金: API 入力 $10 / 出力 $50 per 100 万トークン（前世代の約 2.5 倍）。
  ChatGPT は Plus 月額 3,000 円以上。無料プラン非対応。
- 提供はクラウドのみ（API / Azure / Bedrock）。**ローカル実行の記載なし。**
  Zero Data Retention 対応の言及あり（Private Safety Processing はテスト中）。

## 2. 正直な差分表（SIDRA = 2026-09-07 時点: テンプレ 10 種・計器約 70・
テスト 2,288 関数・qwen2.5:3b ローカル）

| 軸 | GPT-6 Astra | SIDRA 今 | 差をどうするか |
|---|---|---|---|
| 素の頭脳（推論・文章） | 圧倒的に上 | 3B ローカル | **追える最大のレバー = ローカルモデル増強**（→C-1132） |
| 文脈長 | 105 万 | 8,192＋RAG 引用 | 「全部読む」は追わず「探して当てる」を強化（→C-1133/C-1134） |
| ゲーム生成 | 汎用コード生成（**検証なし**。Playco の「50%減」は裏返せば手直しが 50% 残る） | 10 型・**実プレイ検証済み保証**＋言葉の修正ループ＋調整パネル | 保証は優位。自由度の差を部品化（C-1114）と「枠内の自由」（→C-1135）で詰める |
| PC 操作エージェント | OSWorld 72.6% | なし | **追わない（明記）**。SIDRA の役目は資産を作ることで、社長の PC を操作することではない |
| マルチモーダル | ネイティブ統合 | なし（画像スロット受け皿のみ） | ローカル画像モデル導入は E 節の社長判断（帰国後） |
| 1 回あたりのコスト | API $10/$50 per 100 万 tok・Plus 月 3,000 円〜 | **0 円** | 構造的優位。維持 |
| データの行き先 | クラウドのみ（ZDR はあるが送信は前提） | **1 バイトも外に出ない** | 構造的優位。維持 |
| 成果物の所有 | チャット内・要エクスポート | 単一 HTML/OBJ/MD がそのまま自社資産 | 構造的優位。維持 |
| 正直さの保証 | もっともらしさ（検証機構の記載なし） | 引用必須・作れない時は明言・嘘を計器で測る | 優位。**GPT-6 が構造的に持てない差別化** |

## 3. 結論（戦い方）

3B 対フロンティアで「素の頭脳」を並べるのは物理的に無理で、**追うべき差と
追わない差を分けるのが正しい**。

- **追う差（4 件、下の C 項目）**: 頭脳の増強（機械が許す最大のローカル
  モデル）／探して当てる力（索引の器と文脈予算）／生成の自由度（部品化＋
  枠内の自由）。
- **追わない差（明記）**: 105 万トークンの丸読み・PC 操作エージェント・
  クラウド前提のマルチモーダル。これらは SIDRA の存在理由（ローカル・0 円・
  持ち出しゼロ）と交換でしか得られない。
- **広げる差**: §9 で確認済みのとおり、市場の 3 大不満（失敗課金・意図
  理解・持ち出し不可）は SIDRA では構造的に発生しない。GPT-6 の登場は
  この構図を変えない——むしろ API 単価が前世代比 2.5 倍になったことで
  「1 回 0 円」の差は開いた。

## 4. 反映先

C-1132（モデル増強キット）/ C-1133（sqlite+FTS5 昇格）/ C-1134（文脈予算の
実測拡大）/ C-1135（枠内の自由）。外部 LLM API 不使用の決まりは維持
（GPT-6 API を SIDRA に組み込む選択は、するなら社長の明示判断＝E 節）。
